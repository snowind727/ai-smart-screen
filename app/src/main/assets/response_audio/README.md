# 响应语音文件夹

此文件夹用于存放唤醒词检测成功后的响应语音文件。

## 使用说明

1. **文件格式**：仅支持 WAV 格式（`.wav` 扩展名）
2. **文件命名**：可以任意命名，例如：
   - `response_01.wav`
   - `hello.wav`
   - `beep.wav`
   - 等等

3. **播放逻辑**：
   - 检测到唤醒词后，系统会从此文件夹中**随机选择一个** WAV 文件播放
   - 播放完成后，自动开始录制用户语音（3秒）
   - 录音完成后，重新开始监听唤醒词

## 添加响应语音

将你的 WAV 格式响应语音文件复制到此文件夹即可。

**注意**：文件会被打包到 APK 中，建议单个文件不要太大（建议 < 1MB）。
